# Course Brief Template

Use this template when the user wants a new premium course but has only partial context.

## Required inputs

- Client or project name
- Course title
- Intended audience
- Main promise of the course
- Number of weeks or modules
- What learners should be able to do by the end

## Story inputs

- Main plot or transformation arc
- Character names and roles
- Tone of narration
- Voice preference
- Visual style direction

## Learning design inputs

- Core mental models to build
- Key skills per week
- Specific activities learners should complete
- Deliverables or capstones
- Any constraints on tools, language, or pacing

## Premium output target

The default target is:

- storyboard-first narrated slides
- premium voiceover
- one clean top play button
- mobile-safe visual framing
- three question sets per major story block
- activities that reinforce transfer, not just recall

## Recommended structure for a 5-week course

1. Week 0: orientation, stakes, characters, and why this matters
2. Week 1: first mental model and the first breakthrough
3. Week 2: evidence, systems, or analysis
4. Week 3: building or applied execution
5. Week 4: capstone, portfolio, or presentation
